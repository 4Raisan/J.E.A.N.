# Project 12 — Spoken result rendering

render_prompt.py extracts Dodaios's _delegate_result_prompt and its
constants from dodaios/realtime/session.py. It asks a realtime voice model
to speak a concise rendering of a trusted result while retaining names,
counts, and success/failure meaning. The prompt test verifies the extraction.
Actual shortening and speech require the realtime provider. This folder
currently contains the rendering prompt, without a provider or playback demo.

For the local adaptation, run python speak_result.py result.txt --model TAG
with a running Ollama instance and an installed model. Add --failed for a
failed result. The spoken text is generated by Ollama and played through
Project 9's Windows speech path. This is a different transport and voice
from Dodaios. No model is currently installed in the checked Ollama instance,
so this end-to-end rendering path remains unverified.
